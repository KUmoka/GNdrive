# ローカルLLMレビューの採用判定

指定モデルqwen/qwen3.8-27bへ仕様全文を渡し、レビュー本文を取得した。Qwen_Review.mdは未修正のモデル出力であり、仕様を上書きしない。

| 指摘 | 判定 |
| --- | --- |
| 取得・予約・実績を分け、無料効果と二重請求を防ぐ | 採用。仕様12節には既に順序が定義されているため「順序が曖昧」という断定は採用しない。実受入量でなく、効果へ利用できる実生成・実取得量が効果配分の基準 |
| TA解除時の支払済み予算固定 | 採用。ただし「予算流用と差額返却で二重消費する」は必然ではない。「不足分だけ返却」は誤り。通常出力再計算後の未使用分を返却し、追加取得しない |
| Field複数対象費用・停止時の保護解除 | 採用。維持費は粒子費用、反発には2Fの出力枠と2FΔtの粒子費用がある。維持費まで力の枠へ換算する提案は採用しない |
| 保存復元時の整合確認 | 採用。ただしVessel IDをPartの恒久識別子へ混ぜると分離結合で不安定になる。Part安定IDとVessel設定の継承規則を分離する |
| 確定仕様・暫定案・未検証の分離、差分レビュー | 採用。モデルの提案や試験実行主張を、そのまま実装・検証実績として扱わない |

実装案では上記を第3〜5節の契約と第8節の開発手順へ反映。モデルだけで実装案の正しさを保証したものではない。

効率上の結果: 初回3500出力トークンでは推論に使い切り本文が空だった。上限10000へ変更した2回目は5011トークンで完結。小さなコード依頼に分割し、空本文・finish_reason=lengthを失敗として扱う。常に10000を最適値とする意味ではない。
