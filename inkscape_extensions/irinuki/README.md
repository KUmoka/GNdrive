# 入り抜き生成 Inkscape Extension

選択した曲線Aと2ノード線分Bから、Aの端末側部分曲線を切り出し、NAnにおける法線で鏡映した入り抜き用パスBを生成する Inkscape 拡張です。

## インストール

1. このフォルダ内の `irinuki_generate.inx` と `irinuki_generate.py` を Inkscape のユーザー拡張フォルダへコピーします。
2. Inkscape を再起動します。
3. メニューの `エクステンション > KUmoka > 入り抜き生成` から実行します。

ユーザー拡張フォルダは Inkscape の `編集 > 環境設定 > システム > ユーザーエクステンション` で確認できます。

## 使い方

1. 曲線Aを選択します。
2. 2ノード線分Bを追加選択します。
3. `入り抜き生成` を実行します。

選択順がうまく取れない環境では、GUIの `A/Bの判定方法` を `重なり順: 下=A, 上=B` に切り替えてください。

## 初期実装の内容

- BのAに近い端点を NB1 として判定します。
- NB1とNB2の中点に最も近いAノードを NAn として判定します。
- NAnに隣接するA区間のうち、NB1に近い区間を対象にします。
- 対象区間の終端から `Bの長さ / 2` だけ戻った部分曲線を切り出します。
- 切り出した曲線を、NAnにおける法線で鏡映して接続します。
- 元Bのスタイルとパスエフェクトを引き継げます。

## 制限

- 入力Bは2ノードの通常パスを想定しています。
- Aの対象区間より `Bの長さ / 2` が長い場合、初期設定ではエラーにします。
- 弧長と最近傍判定はサンプリング近似です。
